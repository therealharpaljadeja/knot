# Support

Knot is experimental, unaudited software maintained by an open-source
community.

## Questions

Use GitHub Discussions when enabled for setup help, architecture questions, and
ideas that are not yet scoped enough for an issue. Include your operating
system and tool versions, but never include a private key, seed phrase,
keystore, wallet connection ID, or private RPC URL.

## Bugs

Use the GitHub bug report form for reproducible, non-security problems. Include
the smallest reproduction and sanitized logs.

## Security

Do not ask for vulnerability help in public. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Transactions and lost funds

Maintainers cannot reverse transactions, recover wallet keys, return gas, or
modify immutable deployments. Never send funds to a contributor or maintainer
who claims they can recover a wallet or transaction.
